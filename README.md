этот скрипт  = бот в телеграмм, требует BOT_TOKEN в .env, требует aiogram, python-dotenv и storagedb.py из репозитория
aiogram и python-dotenv ставяться с помощью pip install в терминале
бот имеет несколько функций
1. на /start отвечает указанным текстом
2. имеет эхо
3. имеет 3 кнопки которые вызываются с помощью /menu
4. есть кликер который сохраняет кол-во кликов в sqlite
